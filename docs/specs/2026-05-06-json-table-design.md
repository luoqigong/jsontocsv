## 1. 产品定位与差异化

### 1.1 一句话定位

**一个把 JSON 当作 Excel 来用的浏览器工作台**:粘贴 JSON 后立刻得到可排序、可筛选、可编辑列名/列序/类型的真实表格,导出 CSV 或带样式的 Excel。

### 1.2 核心价值主张

- **所见即所得**:粘贴瞬间得到结构化表格预览,不是 CSV 文本框,不是再下载一次才能看
- **复杂 JSON 不卡壳**:`{code:0, data:{list:[...]}}` 这种 API 包裹结构、深嵌套、JSON Lines,工具自动识别;嵌套数组提供 4 种处理策略
- **拿到就能用**:导出 Excel 默认带表头加粗、列宽自适应、冻结首行,不用再到 Office 里手工美化
- **零隐私担忧**:100% 浏览器内运行,JSON 数据不上传任何服务器

### 1.3 目标用户画像

兼顾两类用户,UI 默认友好,高级选项收纳在「高级」折叠区。

| 类型 | 特征 | 关键诉求 |
|------|------|----------|
| **开发者**(40%) | 后端 / 前端,会读 JSON | API 响应快速变表格、嵌套展开、JSONL 支持 |
| **业务人员**(60%) | 产品 / 运营 / 数据分析师 / 项目经理 | 不懂术语、要预览、要直接拿到能用的 Excel |

### 1.4 与现有工具的差异化矩阵

| 能力 | BeJSON / JSON.cn | WeJSON | CSVJSON / Kidelight | **本产品** |
|------|------------------|--------|---------------------|----------|
| 真实表格预览(排序/筛选/搜索) | 否 | 否 | 否 | ✅ |
| API 包裹结构自动识别 | 否 | 否 | 否 | ✅ |
| 嵌套多策略(扁平/字符串/爆炸/分 Sheet) | 单一 | 单一 | 单一 | ✅ 4 策略 |
| 列编辑(改名/调序/隐藏/类型) | 仅勾选 | 字段勾选 | 列顺序 | ✅ 全套 |
| Excel 自带样式(粗体/列宽/冻结) | 否 | 否 | 否 | ✅ |
| 模板保存(本地) | 否 | 否 | 否 | ✅(P1) |
| URL 拉取 | 否 | 否 | 否 | ✅(P1) |
| 中英双语 | 仅中 | 仅中 | 仅英 | ✅ |
| 隐私(纯前端) | 部分 | 部分 | ✅ | ✅ |

## 2. 功能需求

### 2.1 数据输入(P0)

| 子项 | 描述 | 备注 |
|------|------|------|
| 文本粘贴 | 大文本框粘贴 JSON | 默认 |
| 文件上传 | 拖拽 / 点击选择 `.json` `.jsonl` `.txt`,最大 50MB | 浏览器内存限制 |
| 示例数据 | 内置 5 类典型示例(扁平、嵌套、API 包裹、JSONL、超大数组)一键加载 | 帮助新手 |
| URL 拉取(P1) | 输入 URL 自动 fetch;经 Cloudflare Pages Functions 同源代理避开 CORS | 见 §4 架构 |

**校验**:
- 解析失败时高亮第一处错误位置(行号 + 列号),给修复建议(如多余逗号、引号未闭合)
- JSON Lines 自动检测(每行独立 JSON 对象 → 视为对象数组)

### 2.2 智能路径识别(P0)

**问题**:用户粘贴的 JSON 经常不是顶层数组,例如 `{code:0, message:"ok", data:{list:[...]}}`。市面上的工具基本都直接对顶层做 flatten,得到一行带 `data.list.0.x` 的丑数据。

**方案**:
1. 解析后扫描所有路径,收集「值是对象数组(长度 ≥ 2)」的路径
2. 按「数组长度优先 + 路径深度浅优先」排序,默认选第一名
3. UI 上展示一个「数据数组路径」选择器:`<root>` / `data` / `data.list` / `result.items` 等候选,用户可手动切换
4. 路径切换后表格实时更新

**边界情况**:
- 顶层就是数组 → 自动选 `<root>`,不显示选择器(简化)
- 没有任何数组 → 视为「单对象」,渲染为 1 行,提示用户
- 多个等长数组(罕见)→ 都列出,用户选

### 2.3 多策略嵌套处理(P0)

行内字段如果是对象或数组,提供 4 种策略,默认「扁平化」:

| 策略 | 例子(原:`{user: {name:"a", age:1}}`) | 适用 |
|------|---------|------|
| **扁平化(dot)** | `user.name=a, user.age=1` | 嵌套对象,默认 |
| **字符串化(JSON)** | `user='{"name":"a","age":1}'` | 不想展开,留作原样 |
| **爆炸成多行** | `tags:["a","b"]` 一行变两行 | 一对多关系,数组 |
| **拆成多 Sheet**(仅 Excel) | 子数组单独一个 Sheet,父表加外键列 | 复杂关系数据,Excel only |

**UI**:
- 全局默认策略 + 每个嵌套字段单独覆盖(「高级」面板)
- 实时预览策略切换效果

### 2.4 表格预览(P0)

基于 **TanStack Table (Vue Adapter)** + 虚拟滚动。

| 特性 | P0 | 备注 |
|------|----|------|
| 列排序(单/多列) | ✅ | 升序/降序/取消三态 |
| 列宽拖拽 | ✅ | |
| 列冻结(首列) | ✅ | |
| 虚拟滚动 | ✅ | 5万行内丝滑 |
| 行高亮 / 选中 | P1 | |
| 行编辑(改值) | P2 | 不在范围 |

> 说明:全表搜索 / 列内搜索 / 多条件过滤 都统一在「§2.6 行过滤」面板里,不在表头重复入口,UI 保持简洁。

### 2.5 列编辑(P0)

侧边「列管理」面板,左侧是列列表,可以:

| 操作 | 描述 |
|------|------|
| 重命名 | 双击列名编辑,导出时使用新名 |
| 调整顺序 | 拖拽排序 |
| 隐藏 / 显示 | checkbox |
| 类型转换 | 下拉选:文本 / 整数 / 小数 / 日期 / 布尔;选错给出每行错误数 |
| 格式化 | 日期格式(YYYY-MM-DD / ISO / 时间戳)、数字小数位、千分位 |

**说明**:类型转换是「展示 + 导出层」的转换,不破坏原始 JSON。

### 2.6 行过滤(P0)

顶部统一过滤栏,集成所有筛选能力:

- **全表搜索**:任意列含关键字
- **指定列搜索**:选中列后输入关键字
- **多条件叠加(AND)**:每个条件 = 列 + 操作符(`>`, `<`, `=`, `!=`, `contains`, `starts with`, `regex`) + 值;条件可增删
- 显示「当前 X / 总 Y 行」
- **导出时可选「仅导出过滤后的行」**

> 不支持 OR(MVP 范围控制);如需 OR 走 regex 或多次导出。

### 2.7 导出 CSV(P0)

| 选项 | 默认 | 备注 |
|------|------|------|
| 分隔符 | `,` | 可选 `,` `;` `\t` `|` |
| 引号策略 | 必要时加 | 含分隔符/换行/引号才加 |
| 编码 | UTF-8 BOM | BOM 保证 Excel 中文不乱码;可关 |
| 行尾 | `\r\n` | 可切 `\n` |
| 表头 | 含 | 可关 |
| 仅过滤后的行 | 否 | 可开 |

文件名:`原文件名_YYYYMMDD_HHmm.csv`,用户可改。

### 2.8 导出 Excel(P0,差异化加分项)

使用 **ExcelJS** 写入(SheetJS 写入不支持样式)。

**默认即美化**(可关):
- 表头加粗 + 浅灰背景
- 列宽根据内容自动(上限 50 字符)
- 冻结首行
- 日期 / 数字按列类型应用单元格格式
- 第一行筛选器(自动套用 Excel 自带筛选下拉)

**可选**:
- 多 Sheet(配合 §2.3「拆成多 Sheet」策略)
- 输出 .xlsx(默认)或 .xls(兼容老 Office,P2)

### 2.9 模板保存(P1)

将「数据数组路径 + 嵌套策略 + 列设置(名/序/隐藏/类型)」打包为模板,IndexedDB 本地存储。

- 模板列表:卡片式,显示名称、最近使用时间
- 应用模板:对当前 JSON 一键套用;字段不匹配时给出警告
- 导出 / 导入模板 JSON 文件,方便分享

### 2.10 转换历史(P1)

每次「确认转换」时记录元数据(JSON 摘要、字段数、行数、设置快照、时间),不存完整数据。

- 最多 20 条;先进先出
- 一条记录可还原设置(数据需重新粘贴/上传)

### 2.11 URL 拉取(P1)

- 输入框输入 URL → 经 Cloudflare Pages Functions `/api/fetch?url=...` 同源代理 → 返回 JSON
- Pages Function 限流(每 IP / min 30 次)、URL 白名单允许任意 https,黑名单内网/loopback
- 失败给出明确原因(网络 / 4xx / 5xx / 非 JSON)

### 2.12 国际化(P0)

- 默认中英双语,基于浏览器 Accept-Language 自动选,顶部可切换
- 仅 UI 文本翻译;数据本身不动

### 2.13 暗色模式(P0)

- 跟随系统 / 手动切;CSS 变量驱动

## 3. 非功能需求

### 3.1 性能

| 指标 | 目标 |
|------|------|
| 首屏 LCP | < 1.5s(Cloudflare Edge) |
| 5 万行 JSON 解析 + 渲染 | < 3s |
| 列排序 / 筛选响应 | < 200ms |
| 首屏 JS(gzip,不含懒加载) | < 150KB |
| ExcelJS 等大依赖 | 懒加载,用户点导出 Excel 时才下载 |

### 3.2 隐私与安全

- 100% 客户端处理(P0 范围),JSON 不离开浏览器
- 无第三方追踪 / 无 GA / 无埋点(可选 Cloudflare Web Analytics,只看流量,不识别用户)

- URL 拉取功能(P1)的 Pages Function 不记录请求体,只记录访问次数

### 3.3 浏览器兼容

- Chrome / Edge / Firefox 最近 2 个大版本
- Safari 最近 2 个大版本
- 不支持 IE
- 移动端(iOS Safari / Android Chrome)可用,但 UI 优先桌面

### 3.4 可访问性

- 键盘可导航(Tab / 方向键 / Enter)
- 主要按钮有 aria-label
- 颜色对比度 ≥ WCAG AA

## 4. 技术架构

### 4.1 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 构建 | Vite 5 | 快、产物对 Cloudflare Pages 完美兼容 |
| 框架 | Vue 3 + Composition API + `<script setup>` | 体积小、上手快、生态够用 |
| 状态管理 | Pinia | 官方推荐,API 简洁;模板/历史用它管 |
| 路由 | Vue Router | 单页 + `?route=` 浅路由 |
| 表格 | `@tanstack/vue-table` | Headless,自由控制 UI;虚拟滚动用 `@tanstack/vue-virtual` |
| Excel 写入 | ExcelJS | 支持样式 |
| Excel 读取(可选) | SheetJS(`xlsx`) | 兼容性最好,P2 反向用 |
| JSON 处理 | 自写;不用 ajv | 不需要 schema 校验,只要 path 扫描 |
| 工具库 | radash 或手写小函数 | 不引 lodash 减包体 |
| 样式 | UnoCSS 或 Tailwind v4 | 原子化,按需 |
| i18n | vue-i18n | 标准选择 |
| 本地存储 | IndexedDB(`idb` 库) | 模板 / 历史 |
| 部署 | Cloudflare Pages + Pages Functions | 静态 + P1 URL 代理 |

### 4.3 数据流

```
用户输入 (粘贴/上传/URL/示例)
    ↓
parser.parse() → AST + 错误信息
    ↓
pathFinder.detect(AST) → 候选路径列表
    ↓ (用户可改)
[选定路径]
    ↓
flattener.apply(数组, 策略) → 行数组(每行扁平 object)
    ↓
typeInfer.infer(行数组) → 列元数据(name, type, sample)
    ↓
[用户在 columnPanel 修改列设置]
    ↓
transform.apply(行数据 + 列设置) → 显示数据
    ↓
[在 tableView 渲染,可排序/筛选/搜索]
    ↓
[导出时:exporter.toCsv() 或 exporter.toExcel()]
    ↓
浏览器 Blob 下载
```

### 4.4 错误处理与边界情况

| 场景 | 处理 |
|------|------|
| JSON 语法错误 | 高亮行号 + 详细原因(用 `jsonc-parser` 或自写) |
| 文件 > 50MB | 提示「太大,请用命令行工具」 |
| 数组每行字段不一致 | 取并集,缺失字段在表格内显示空,导出时也是空 |
| 数组每行类型混杂(字符串+对象混合)| 全转字符串,警告 |
| 类型转换失败行 | 转换列高亮失败单元格,鼠标悬停显示原值;导出时可选「保留原值」或「置空」 |
| 路径检测后无任何数组 | 渲染单对象为 1 行;提示用户 |
| 浏览器内存溢出 | 监听 `crash`,无法捕获;事先按行数预警(>10万行)|

## 6. 验收标准

每个 P0 子需求都有验收用例。示例:

### 6.1 智能路径识别

- 输入:`{code:0, data:{list:[{a:1},{a:2}]}}` → 默认选 `data.list`,表格显示 2 行 1 列
- 输入:`[{a:1},{a:2}]` → 不显示路径选择器,直接表格 2 行
- 输入:`{a:1, b:2}` → 路径 `<root>`,显示 1 行,提示「检测到单对象,展示为 1 行」

### 6.2 嵌套策略

- 输入:`[{user:{name:"a",age:1}},{user:{name:"b",age:2}}]`
  - 扁平化 → 2 列(`user.name`, `user.age`)
  - 字符串化 → 1 列(`user`,值是 JSON 字符串)
- 输入:`[{id:1,tags:["a","b"]},{id:2,tags:["c"]}]`
  - 爆炸成多行 → 3 行(id=1/tags=a, id=1/tags=b, id=2/tags=c)

### 6.3 Excel 美化

- 任意输入导出 Excel 后,用 Office 365 打开:
  - 第一行加粗、浅灰底色
  - 第一行已冻结(下滚时仍可见)
  - 列宽贴合内容
  - 第一行有筛选下拉

### 6.4 性能

- 5 万行 JSON(约 30MB)粘贴后,从「点击转换」到表格首屏渲染 < 3 秒
- 任意列排序响应 < 200ms

## 7. 风险与开放问题

### 风险

| 风险 | 缓解 |
|------|------|
| TanStack Vue Adapter 较新,Vue 3 生态比 React 弱 | 关键功能(虚拟滚动)有官方示例,实在不行降级用 vxe-table |
| ExcelJS 在浏览器写大文件性能 | 5 万行实测;超过用 Web Worker 异步 |
| Cloudflare Pages Functions 的 CPU/请求时长限制(免费版 50ms) | URL 代理是简单 fetch,延时主要在外网,通常够;超时给提示 |
| 大文件导致浏览器内存爆 | UI 上限 50MB / 10 万行,超过提示用命令行 |
| MVP 范围还是大 | P0 锁死,任何 P1 项不允许「捎带做完」 |

### 开放问题(待决)

1. **域名**?(如 `jsontable.app`、`json2grid.io` 等)— 待用户决定
2. **是否要开源**?— 影响 README、贡献指南。开源对差异化和信任度有加分
3. **是否要做 SEO 着陆页**(每种格式一个着陆页:json-to-csv、json-to-excel、jsonl-to-csv)— SEO 红利大,P1 加
4. **变现模式**?— P0 不考虑,纯免费;后期可考虑「批量大文件 / API 接入」VIP
